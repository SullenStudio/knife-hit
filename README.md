# Knife Hit — Sullen Studio

Throw knives into a spinning log. Every stuck blade becomes a hazard.
Built with [Kaplay](https://kaplayjs.com) + Vite.

**Play:** https://sullenstudio.github.io/knife-hit/

## Controls

| Input | Action |
| --- | --- |
| Space / Enter / tap | throw |
| Phone | PLAY / THROW buttons |

Stages speed up, reverse, and start wobbling. Best score stays in `localStorage`.
Phone shows a big THROW button.

```bash
npm install
npm run dev
```
